# Bioinformatics / genomics — scarcity note

Public GPT-6 Astra cases that are **clearly** genomics or wet-lab science are scarce.

What exists so far:

- Official **computer-use demo** of MultiQC / Bcftools pages on the [launch page](https://openai.com/index/gpt-6-astra/) — UI navigation, not a study. See [official-science.md](official-science.md).
- Official **GeneBench Pro** score on the Science & Health table (~37%) — an agent *benchmark*, not completed genomics research. See [failures.md](failures.md).

This file is **not** a wishlist for plant / *Vitis* / aDNA / private capture-panel work. Those belong in lab repos when they are real; do not treat them as Astra gallery claims.

If you have a public, attributable Astra session (author + URL + evidence boundary), open a PR per [CONTRIBUTING.md](../CONTRIBUTING.md).
