# Awesome Astra Science

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

[中文](README.zh.md) · English default

Curated **GPT-6 Astra** cases for scientists, bioinformaticians, and lab engineers: desktop tool use, long-horizon computer use, research workflows, and cautionary connected-tool stories.

This is a catalog with attribution, not a tutorial, and **not** an official OpenAI repository.

Classic entertainment / 3D / game ceiling cases are included **selectively** when they teach a control loop or tooling habit you can transfer to lab work. For the broad Astra gallery, see [helloianneo/awesome-gpt6-astra](https://github.com/helloianneo/awesome-gpt6-astra).

## Scope

**In:** tool use a researcher would recognize; measurable computer use; workflow patterns; cautionary sends.

**Out:** pure game / vibe 3D dumps with no methods transfer (keep those upstream in awesome-gpt6-astra).

**Evidence:** author-reported and official demos unless a PR proves otherwise. This catalog does not independently reproduce runs.
