# Awesome Astra Science

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

[中文](README.zh.md) · English default

Curated **GPT-6 Astra** cases for scientists, bioinformaticians, and lab engineers.

Preview stills are chosen to show **the tool or result**, not a random video poster. Some stills are frames we extracted from the author’s own video (hosted under [`media/`](media/)); others are the author’s tweet photos. Copyright stays with the authors. Classics also appear in [helloianneo/awesome-gpt6-astra](https://github.com/helloianneo/awesome-gpt6-astra).

## Scope

**In:** tool use a researcher would recognize; measurable computer use; workflow patterns; cautionary sends.

**Out:** leading with game / vibe posters that hide the tool.

**Evidence:** author-reported and official demos unless a PR proves otherwise.
